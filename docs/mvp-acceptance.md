# MVP 功能验收记录（历史阶段 API 0.3）

> 本页记录上一阶段当时的测试与运行状态，保留原证据不回填新计数。API 0.4 的恢复码、Cookie、Markdown、数据控制和备份恢复等后续结果，请看[当前可持续内测验收](usability-acceptance.md)。下文“当前”均指本次历史记录创建时，不作为最新运行配置证明。

验收日期：2026-11-19（Asia/Shanghai）。范围来自 [idea](../idea.md) 与后续授权：基本实现功能闭环、提供简单测试客户端和后台，**不含正式视觉设计，也不等于公开生产上线**。本记录区分模拟、实际 Mock 服务、真实中转三类证据，不将它们合并为一次全量测试。

## 结论与当前运行状态

- 功能性 MVP 已在 `hklite-lv4` 的受保护开发环境完成联调；所有依赖、lint、编译、自动化与 Chromium 均在服务器执行，本地仅留源码/文档。
- 现有单个 `allira-dev` 服务以低权限 `allira` 运行，只监听 `127.0.0.1:8000`，单 worker、无 reload、禁用代理头信任；未启用开机自启，没有开放公网业务端口或修改防火墙/域名。
- `/test/` 为普通功能测试客户端，`/admin/` 为独立认证的开发管理面板。通过 SSH 隧道访问，不能公开开发登录或控制台。
- 当前运行配置为用户授权的测试中转，经济模型 `deepseek-flash`，每次上游输出上限 256 Token。真实极速模型未配置，`fast` 按配置回退经济并退差价；代码默认仍为 Mock。
- 中转凭据仅在服务器受保护环境文件；源码、SDK、浏览器和本地镜像不包含真实 Key。回归脚本须先确认 Mock，不能对当前真实配置运行业务 live 全量测试。
- 源码存在于远端工作区与轻量本地镜像。**本轮 MVP 尚未 commit/push；GitHub 的旧提交不包含这些新增功能。** 发布状态必须另以实际提交与远端核验为准。

### PWA 验收的确切含义

临时非隐身 Chromium 配置验证六个公开缓存路径：测试入口、manifest、哈希 chat JS/CSS、192/512 PNG 图标。图标实际解码、CDP `Page.getInstallabilityErrors` 为空；API、后台和身份数据不在缓存中。Chromium 159 的持久配置测试使用 `Network.overrideNetworkState` 同步 `navigator.onLine` 信号，**同时另断言真实 API 网络请求失败**，不是只修改布尔值冒充离线。离线重载公开壳后没有恢复登录，登录/发送不可用。

这不等于已在 Android/iOS 真机完成安装、软键盘、系统后台恢复或商店分发验收。

## 少量真实中转验证

用户指定 `https://sub.lk1950.xyz/v1`，凭据不记入本文件。只执行有限短请求，不进行真实负载/报价或质量测试：

1. 获取模型列表成功；单次短流探测中，`deepseek-flash` 返回 HTTP 200 / SSE 并正常结束；另一候选 `deepseek-v4.1-flash` 返回 HTTP 502，**没有设为默认或宣称可用**。
2. 完整链路使用现有服务、已编译 Fetch SDK 与 SSE，显式单次经济 Run：`completed`、4 个事件、4 个输出字符、能量扣减 1，首次公开文本约 2022ms。
3. 同 UUID+原文+模式重放仍为原 Run、没有二次扣能量；usage 已结算，历史与规范终态一致，验收会话及登录已清理。输出正文、Token 与 Key 没有打印。

真实链路记录来自 [显式脚本](../scripts/relay-smoke.mjs)，必须手动设置开关；与 [Mock 冒烟](../scripts/smoke.mjs) 分开。单次约 2 秒不是稳定 TTFT 指标，字符数不是 Token 用量，256 Token 是请求输出上限而不是成本统计。极速线路优势、回退在真实多渠道中的行为、缓存计费与长对话质量尚未实测。

## 尚未完成／上线前必须处理

- Gemini 正式视觉；真机移动键盘/安装/恢复体验；流式 Markdown/代码高亮目前不作为已交付能力，现有消息按安全纯文本显示。
- 公网 TLS/域名/反向代理、正式部署与安全评审；当前开发面板、开发登录和单进程任务所有权不可直接扩为公开多实例服务。
- 账号恢复/删除、邮件或二次认证、生产反滥用与分布式限流；成年确认仅自述。
- 自动异机备份、保留期、实际恢复演练、监控告警与生产迁移流程。
- 真实 Token/报价/缓存核算、商业支付、发票或渠道 SLA；目前仅整数测试能量和 CDK 闭环。
- 更可靠的长期记忆/摘要评测、提示注入与内容安全治理、完整隐私/合规与外部渗透测试。
- 原始设想的“70% 节省”等比例未经实测，不作承诺；主动问候、TTS 等后续项不纳入本次功能 MVP。
