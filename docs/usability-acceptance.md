# 可持续内测版本验收（API 0.4）

> 历史阶段记录：下文的版本、计数和部署状态对应 API 0.4 验收当时；当前来源上下文、陪伴预设与简单客户端的证据见[API 0.5 验收](context-companion-acceptance.md)。不把旧门禁计数改写为新版本结果。

验收日期：2026-11-19（Asia/Shanghai）。本轮响应“继续完善平台，只把正式客户端视觉留给 Gemini”的授权，在[上一阶段 MVP](mvp-acceptance.md)上补齐日常使用、安全会话、数据控制和维护能力。**结论为 SSH 保护环境中的可持续功能内测，不是公开生产上线、商业计费、内容合规或移动真机验收。**

## 部署结论

- 已部署 API **0.4.0 / 65 个 OpenAPI 路径 / schema4**，现有单个 `allira-dev` 以低权限 `allira`、单 Uvicorn worker 运行，只监听 `127.0.0.1:8000`，无 reload、不信代理头。API 未开机自启；未开放公网端口或改变域名、防火墙与 SSH 登录配置。
- 现有 SSH 隧道保持，测试客户端 `/test/`、独立后台 `/admin/`、文档 `/docs` 可经本地 `http://127.0.0.1:8000` 访问。后台仍需服务器 CLI 签发一次性登录链接，普通账号与开发 userId 不获管理权。
- 部署前核验无活动/预扣任务，保存一致性快照、前端构建及服务器私有原环境；维护期间仅切换非秘密键到 Mock。最终浏览器专项通过并冻结后，已逐字节恢复原受保护中转配置，检查摘要相同，再只重启原服务。恢复后 info=openai、readiness=ready、版本 0.4.0、运行/预扣任务均为零；**没有通过再次生成来验证恢复，没有本轮自动真实模型请求。**
- 恢复的是之前已授权和验证的经济模型 `deepseek-flash`、输出上限 256 Token；真实极速模型仍未配置，按原策略回退经济并退差价。以上不新增真实线路质量、价格、速度或容量证据；上一阶段有限真实链路证据单独保留，不拼成此次回归成绩。
- 新源码均保留远端主工作区和轻量本地镜像。**本轮及此前功能性 MVP 的新增代码尚未 commit/push，GitHub 仍是旧版本。** 不将工作区文件存在当作发布完成，不回传依赖、构建物、浏览器数据、聊天库、环境文件或凭据。

## 已补齐的使用闭环

| 领域 | 本轮能力与主要约束 |
| --- | --- |
| 账号自助与设备 | 密码确认后一次签发 8 个高熵单次恢复码，仅存摘要；恢复成功撤销全部旧会话/恢复码。设备显示非秘密 UUID/时间/标签，支持撤销；密码计算与敏感确认共享有界计算槽、限流及计算后再认证。没有邮件/短信/2FA，也不能在没有恢复码时伪装找回。 |
| 浏览器登录 | 用户明确选择才以短期 Bearer 交换独立 HttpOnly Cookie，原 Bearer 被消费；刷新以 GET 恢复用户和内存 CSRF。类型隔离、同源 Origin/CSRF、默认七天、HTTPS Secure；默认 SDK/公开请求显式 omit，不暗用 Cookie，失效显式 Bearer 不回退。管理 Cookie 完全独立。 |
| 聊天与展示 | 受限 CommonMark token→白名单 DOM，无任意 HTML/外部图片请求，代码复制需手势；64000 字符/4096 token/嵌套 20 超限回退文本。消息节点稳定，100ms 合并流式绘制、终态立即覆盖；网络/EOF/5xx 最多五次 GET 对账/回放，401/协议/主动断开/退出/切换停止，离线等待 online，不自动重发生成 POST。 |
| 历史实用功能 | 本人标题/正文子串检索及绑定 owner/q 的签名游标；JSON/Markdown 完整归档、到合法 completed pair 的幂等新会话分叉。保留严格 UUID/原文/mode，源/目标删除墓碑不重建。修复围栏内角色误识别、自有归档失败片段被误导入成功及跨跳过记录拼对；仅合法原相邻完成对进入 timeline。 |
| 个人数据控制 | 一致账号导出不含系统凭据/管理/提供方字段，但不自动脱敏用户粘贴的聊天秘密；账号上限 1000 会话/100000 记录/32MiB，单会话另限 50000 消息/16MiB，超限拒绝、不静默截断。删号需当前密码、精确确认串和 UI 确认；活动/清理任务拒绝，CDK 留随机核销墓碑、相关审计引用清理，历史备份不承诺物理擦除。 |
| 运维与诊断 | 公开 readiness 只做本地 SELECT 1；独立管理诊断只含非敏感健康/容量/会话/备份元数据。每日同机一致性快照保留最近 7 份，SHA/完整性/FK 校验、新离线目标恢复、撤销凭据与中断任务恢复退款。freshness 明示不是校验或恢复证明，不对真实模型发探针。 |

旧能力持续保留：账号注册/登录、用户隔离、角色与核心记忆/有界摘录、JSON/Markdown/text 导入、REST/SSE/cancel/replay、经济/极速业务模式与整数测试能量/CDK、独立管理面板以及仅公开壳 PWA。完整协议见 [API](api.md)、[SDK](../packages/client/README.md)。

### 最终 PWA 与历史失败说明

- 最终专项使用新的 **non-incognito Chromium profile**，显式允许 SW，验证六项精确公开资源、同源 PNG 192/512 解码、CDP installabilityErrors 为空。
- 真实断网模式下私有 API 请求失败，公开壳仍可刷新且不显示私有登录/草稿；联网后才以服务端 Cookie 恢复。API/admin/POST/Token/聊天/恢复码/私有下载不进入缓存，没有 localStorage/IndexedDB 秘密写入。
- 旧独立 PWA 用例曾在 SW ready 阶段超时，原因是路由测试全局 `serviceWorkers:block` 被继承。仅给该分支显式 allow，没有修改生产 SW 算法；**没有反复重跑旧业务 live，也不将其历史失败抹成全绿**。最终专项重新覆盖安装与离线断言；旧聊天/admin/MVP 兼容曾另次通过，证据不合并为同次全量成绩。

## 备份与保留的运行事实

- `allira-backup.service` 手动执行成功；`allira-backup.timer` 已启用并 active，每日 UTC 19:15（北京时间次日 03:15）后随机 0–300 秒运行，Persistent=true，保留最近 7 份本工具合法快照。业务 API 仍 disabled at boot，两者不混淆。
- 快照仅在服务器私有目录，文件 0600/目录 0700，标准库 SQLite backup API；验证 SHA-256/size/integrity/FK，文件及目录 fsync、排他创建和同盘发布。锁占用 fail closed，不按年龄偷删锁。
- 恢复拒绝已存在目标及 `-wal/-shm/-journal`，包括悬空链接；新副本撤销会话/管理码/恢复码，迁移后回收 interrupted run 并退款。后台只看有界新鲜度，不把 recent 当作真正恢复验证。
- 历史备份保留旧密码摘要、旧删除状态和聊天，不能直接上线回滚账号删除/凭据变更；本轮没有云复制、异机、自动故障切换、加密备份或全局正文保留期。操作见[远程开发](remote-development.md)。
